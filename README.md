## 🎨 Sobre o Projeto

Portfólio profissional de Alessandro Rodrigues, Designer UX/UI Sênior com mais de 10 anos de experiência em design digital e desenvolvimento front-end. O projeto apresenta uma interface moderna e responsiva, destacando habilidades em design de interfaces, desenvolvimento web e consultoria em UX/UI.

## ✨ Características

- **Design Responsivo**: Interface adaptável para todos os dispositivos
- **Performance Otimizada**: Build otimizado com Next.js 14
- **SEO Avançado**: Meta tags, Open Graph e Schema.org implementados
- **Analytics**: Google Analytics integrado para monitoramento
- **Acessibilidade**: Foco em usabilidade e acessibilidade
- **Animações**: GSAP para animações suaves e interativas
- **Carrosséis**: Swiper.js para sliders e carrosséis
- **Layout Isotópico**: Isotope.js para layouts dinâmicos

## 🚀 Tecnologias Utilizadas

### Frontend
- **Next.js 14.1.0** - Framework React com SSR/SSG
- **React 18.2.0** - Biblioteca JavaScript para interfaces
- **GSAP 3.12.5** - Animações avançadas
- **Swiper 8.4.7** - Carrosséis e sliders
- **Isotope 3.0.6** - Layouts dinâmicos e filtros

### Estilização
- **CSS Modules** - Estilos modulares
- **Tailwind CSS** - Framework CSS utilitário
- **SCSS** - Pré-processador CSS

### Deploy e Analytics
- **Vercel** - Plataforma de deploy
- **Google Analytics** - Monitoramento de tráfego

## 🛠️ Instalação e Configuração

### Pré-requisitos
- Node.js 18+ 
- npm ou yarn

### Passos para Instalação

1. **Clone o repositório**
```bash
git clone https://github.com/seu-usuario/alebrcom.git
cd alebrcom
```

2. **Instale as dependências**
```bash
npm install
# ou
yarn install
```

3. **Configure as variáveis de ambiente**
```bash
# Crie um arquivo .env.local (opcional)
cp .env.example .env.local
```

4. **Execute o projeto em desenvolvimento**
```bash
npm run dev
# ou
yarn dev
```

5. **Acesse o projeto**
```
http://localhost:3000
```

## 📜 Scripts Disponíveis

```bash
# Desenvolvimento
npm run dev          # Inicia servidor de desenvolvimento

# Build
npm run build        # Cria build de produção
npm run start        # Inicia servidor de produção

# Linting
npm run lint         # Executa ESLint
```

## 🚀 Deploy

### Vercel (Recomendado)

1. **Instale o Vercel CLI**
```bash
npm i -g vercel
```

2. **Faça login no Vercel**
```bash
vercel login
```

3. **Deploy para produção**
```bash
vercel --prod
```
